# Cnblog_Pixyll_Skin
博客园中基于SimpleMemory皮肤的仿Pixyll主题皮肤

> -- 注：最新分支见latest --

# Pixyll皮肤更换教程

1. 在博客园账号后台的设置页面中的“基本设置”中，设置博客皮肤为SimpleMemory
2. 在博客园账号后台的设置页面中的“基本设置”中，开通JS权限
3. 在博客园账号后台的设置页面中的“页面定制CSS代码”处勾选“禁用模板默认CSS
4. 将仓库中的“页面定制CSS代码.ccs”中的内容复制到博客园账号后台的设置页面中的“页面定制CSS代码”处
5. 将仓库中的“页脚html代码.html”中的内容复制到博客园账号后台的设置页面中的“页脚html代码”处
6. 其他的东西都不用改。完成之后点击博客园账号后台的设置页面最底部的“保存”
